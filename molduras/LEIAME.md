# Biblioteca de molduras

Coloque aqui os PNGs das fotomolduras. O nome do arquivo (sem `.png`) é o
código usado nos pedidos: `coracao-boyfriend.png` → `--moldura coracao-boyfriend`
ou coluna `moldura` = `coracao-boyfriend` na planilha.

Como exportar do Corel:

- tamanho da **estampa** (ex.: 45 × 45 cm, sem a margem de costura);
- **transparente somente onde vai a foto**; o resto pode ter fundo branco;
- resolução de pelo menos **150 DPI** no tamanho final (45 cm → 2657 px);
- molduras com vários espaços (casal, colagem) recebem as fotos da esquerda
  para a direita e de cima para baixo.

`estampa molduras` lista as molduras e quantos espaços para foto cada uma tem.
